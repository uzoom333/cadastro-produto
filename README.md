# Cadastro de Produto

Projeto da Prova Individual 05 - CMP2304/A03 (Tecnologia de Construcao de Software - PUC Goias).

O objetivo do projeto e registrar todo o ciclo de desenvolvimento com Git, GitHub e GitFlow.
A complexidade visual do sistema nao e o foco: trata-se de um cadastro de produtos em linha de
comando, simples e direto.

## Funcionalidades

- Cadastrar produto (nome, preco e quantidade)
- Listar produtos cadastrados

## Como executar

```bash
python3 main.py
```
